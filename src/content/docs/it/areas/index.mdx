Un’**Area** è un cuboide invisibile nel livello. L’hub Areas originale chiama le Area il sistema di input/output principale di HPL3.

<p class="section-kicker">03 // AREAS &nbsp; REF 03.10</p>

Usale quando qualcosa deve succedere perché il giocatore (o un’altra Entity) è entrato in un volume, ha guardato qualcosa, o perché il volume stesso è un effetto (fog, soundscape, exposure).

:::caution[SOURCE STATUS: WIP]
L’hub Areas SOMA originale è marked as undergoing major editing. Diversi tipi sono elencati ma non hanno articolo (redlink). I parametri non sono inventati qui.
:::

## Workflow tipico

1. Piazza l’Area nel Level Editor (strumento Areas).
2. Dallle un nome. Nome semplice; gli script la cercano per nome.
3. Compila le proprietà che il tipo documenta davvero (collide callbacks, attachment, look-at, campi specifici).
4. Se spara script, metti il callback sulla `.hps` della mappa (o un helper file).
5. Testa in-game. Se non parte mai: note collide-callback di [Trigger Area](/it/areas/trigger-area/) e [Troubleshooting](/it/debugging/).

Helper file nominato dall’articolo Trigger: `helper_area.hps`. Le **pagine** helper dedicate sono redlink; vedi [Helpers](/it/scripting/helpers/).
