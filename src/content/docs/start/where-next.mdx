You should now be able to launch your own mod, open its map in the Level Editor, and change a `.hps` file with a visible result.

## If the last step failed

[Troubleshooting](/debugging/) and the [Wiki FAQ](/debugging/faq/) first. Isolate whether the failure is launcher, editor resources, or script compile.

## Next systems, in a useful order

1. **[Trigger Area](/areas/trigger-area/)** — the basic input. Player walks in, a callback runs.
2. **[PlayerStart](/areas/playerstart-area/)** — where the player appears.
3. **[Level settings](/level-editor/level-settings/)** — global fog and skybox.
4. **[Point lights](/level-building/point-lights/)** and **[Spot lights](/level-building/spot-lights/)**.
5. **[Timers](/scripting/timers/)** and **[Sequences](/scripting/sequences/)** when you need delayed or ordered events.
6. **[Helper files](/scripting/helper-files/)** before a map script grows past one file.
7. **[Entities](/entities/)** when you need an object the player can grab, open, or use.
8. **[Materials](/materials/)** and **[Particles](/particles/)** for look.
9. **[Indoor](/level-building/indoor-level-performance/)** / **[outdoor](/level-building/outdoor-level-performance/)** performance before the map gets large.
