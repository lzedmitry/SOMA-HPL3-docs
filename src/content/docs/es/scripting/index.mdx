La lógica de mapa de SOMA es AngelScript en archivos `.hps`. Un mapa `sample_map.hpm` carga `sample_map.hps` al lado. El paso de script de Getting Started solo cambia `OnStart()` dentro de la clase generada `cScrMap`.
