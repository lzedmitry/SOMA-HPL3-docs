= Entity Class window =
With this window, one can set up properties for the entity. First, a class shall be picked from the combo box at the top of the window. When this is done, a list of variables will appear below them.

> **Figure (original Wiki file, not inlined):** [window_entityclass.png](https://wiki.frictionalgames.com/page/File:window_entityclass.png)

If defined, you can get information on a variable by moving the mouse over it.

> **Figure (original Wiki file, not inlined):** [window_entityclass_tooltip.png](https://wiki.frictionalgames.com/page/File:window_entityclass_tooltip.png)

NOTE: These variables are game-specific.
