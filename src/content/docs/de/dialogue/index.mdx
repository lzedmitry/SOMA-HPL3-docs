Der originale Audition-Hub nennt auch Conversations, Voice Settings und Voice Subjects als Teil des Systems. Eigene Artikel für diese Namen waren im Importbaum nicht; Begriffe der Übersicht, keine Extra-Handbücher.

## Workflow (nur Schritte, die die Overviews tragen)

Voice file → Audition → Conversation-/Subject-Setup wie auf diesen Seiten → Trigger im Spiel (Skript oder Area — siehe Handler-Overview, keinen callback-Namen annehmen, den das Wiki nicht druckt).
