The original [Glossary source](/generated/glossary-source/) is marked stub / under construction. Entries below are only terms that page or the Getting Started / Areas / Modding articles already use.

## A

**Add-on** — A mod that can run along with a stand-alone mod. See [Creating a mod](/modding/creating-a-mod/).

**Agent** — Enemy/NPC-style entity.

**AngelScript** — Language of `.hps` scripts.

**Area** — Invisible cuboid used as HPL3's input/output volume. See [Areas](/areas/).

## C

**Critter** — Small background creature without a full agent script.

## E

**Entity** — World object with behaviour. See [Entities](/entities/).

**entry.hpc** — Mod entry file.

## H

**Helper** — Shared script include. Mechanism: [Helper files](/scripting/helper-files/). Per-helper Wiki pages: missing.

**HPL3** — Engine SOMA shipped with. Not automatically the same as later Amnesia "HPL3". See [What is HPL3?](/start/what-is-hpl3/).

**HPM** — Map file (`.hpm` + `.hpm_*`).

**HPS** — AngelScript source (`.hps`).

## I

**ID handle** — Script identity for an engine object. [ID Handles](/scripting/id-handles/).

## M

**Mod** — Extra content in its own folder.

## P

**Prop** — Interactive entity. Most entities are props.

## R

**resources.cfg** — Tells the engine which resource directories to search.

## S

**SH probe** — Spherical-harmonic lighting probe. Named on the Level Design hub; SOMA article is a redlink.

**Stand-alone mod** — Custom-map mod launched from the SOMA mod launcher. Also called a custom story in the Glossary stub.

**Static object** — Mesh used for collision/visuals without entity behaviour.

## W

**WIP (source)** — Wiki page still being rewritten. Shown as `SOURCE STATUS: WIP` on imported pages.

**WIP mod** — In-development mod, in launcher/setup docs.
