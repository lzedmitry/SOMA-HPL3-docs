Исходный [Glossary source](/ru/generated/glossary-source/) помечен stub / under construction. Ниже только термины, которые эта страница или статьи Getting Started / Areas / Modding уже используют.

## A

**Add-on** — Мод, который может идти вместе со stand-alone. См. [Creating a mod](/ru/modding/creating-a-mod/).

**Agent** — Entity врага/NPC.

**AngelScript** — Язык скриптов `.hps`.

**Area** — Невидимый кубоид — I/O-объём HPL3. См. [Areas](/ru/areas/).

## C

**Critter** — Мелкое фоновое существо без полного agent-скрипта.

## E

**Entity** — Объект мира с поведением. См. [Entities](/ru/entities/).

**entry.hpc** — Файл входа мода.

## H

**Helper** — Общий include скрипта. Механизм: [Helper files](/ru/scripting/helper-files/). Постраничные статьи helper: отсутствуют.

**HPL3** — Движок, с которым вышла SOMA. Не автоматически то же, что поздняя Amnesia «HPL3». См. [What is HPL3?](/ru/start/what-is-hpl3/).

**HPM** — Файл карты (`.hpm` + `.hpm_*`).

**HPS** — Исходник AngelScript (`.hps`).

## I

**ID handle** — Идентичность объекта движка из скрипта. [ID Handles](/ru/scripting/id-handles/).

## M

**Mod** — Дополнительный контент в своей папке.

## P

**Prop** — Интерактивная Entity. Большинство Entity — props.

## R

**resources.cfg** — Говорит движку, какие каталоги ресурсов искать.

## S

**SH probe** — Spherical-harmonic lighting probe. Названа на хабе Level Design; статья SOMA — redlink.

**Stand-alone mod** — Мод с кастомными картами из SOMA mod launcher. В stub Glossary также custom story.

**Static object** — Mesh для коллизии/вида без поведения Entity.

## W

**WIP (source)** — Страница Wiki всё ещё переписывается. На импортированных страницах: `SOURCE STATUS: WIP`.

**WIP mod** — Мод в разработке, в документах лаунчера.
