## Objectif

Un dossier de mod stand-alone qui apparaît dans le lanceur SOMA et démarre sa map d’exemple.

## Prérequis

SOMA installé, selon [Prepare your tools](/fr/start/prepare-your-tools/).

## Étapes

Suivez [Create and launch your mod](/fr/start/create-and-launch-your-mod/) dans l’ordre. Cette page est la checklist. Détails : [Creating a mod](/fr/modding/creating-a-mod/) et [MinimalCustomMapMod](/fr/modding/minimalcustommapmod/).

## Résultat attendu

Le mod copié est dans le lanceur et la map d’exemple tourne.

## Pourquoi ça marche

L’exemple fourni est un `entry.hpc` + `resources.cfg` + map connus pour fonctionner. Le copier évite d’assembler ces fichiers de mémoire.

## Échec courant

Éditer l’exemple original ou le jeu de base. Travaillez dans la copie.
