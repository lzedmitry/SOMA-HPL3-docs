Если шаг Getting Started падает — остановитесь там. Исходный путь сделан так, чтобы сбои лаунчера, редактора, карты и скрипта оставались разделимыми.

## Быстрый путь

1. Убедитесь, что вы в **скопированном моде**, не в `MinimalCustomMapMod` и не в базовой игре.
2. Запуск из SOMA mod launcher.
3. В development mode нажмите **F1**: Show Error List, Show HPL Log ([Debug menu](/ru/modding/developer-debug-menu/)).
4. После правки скрипта **F5** перезагружает карту.
5. Читайте [Developer commands](/ru/modding/developer-commands/).
