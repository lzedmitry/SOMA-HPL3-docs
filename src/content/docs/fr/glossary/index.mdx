La [Glossary source](/fr/generated/glossary-source/) d’origine est marked stub / under construction. Ci-dessous uniquement les termes que cette page ou Getting Started / Areas / Modding utilisent déjà.

## A

**Add-on** — Un mod qui peut tourner avec un stand-alone. Voir [Creating a mod](/fr/modding/creating-a-mod/).

**Agent** — Entity ennemi/NPC.

**AngelScript** — Langage des scripts `.hps`.

**Area** — Cuboïde invisible, volume I/O de HPL3. Voir [Areas](/fr/areas/).

## C

**Critter** — Petite créature de fond sans script agent complet.

## E

**Entity** — Objet du monde avec comportement. Voir [Entities](/fr/entities/).

**entry.hpc** — Fichier d’entrée du mod.

## H

**Helper** — Include de script partagé. Mécanisme : [Helper files](/fr/scripting/helper-files/). Pages Wiki par helper : absentes.

**HPL3** — Moteur livré avec SOMA. Pas automatiquement le même que l’« HPL3 » Amnesia plus tardif. Voir [What is HPL3?](/fr/start/what-is-hpl3/).

**HPM** — Fichier de map (`.hpm` + `.hpm_*`).

**HPS** — Source AngelScript (`.hps`).

## I

**ID handle** — Identité script d’un objet moteur. [ID Handles](/fr/scripting/id-handles/).

## M

**Mod** — Contenu extra dans son propre dossier.

## P

**Prop** — Entity interactive. La plupart des Entity sont des props.

## R

**resources.cfg** — Indique au moteur quels répertoires de ressources chercher.

## S

**SH probe** — Spherical-harmonic lighting probe. Nommée sur le hub Level Design ; l’article SOMA est un redlink.

**Stand-alone mod** — Mod de maps custom lancé depuis le SOMA mod launcher. Aussi appelé custom story dans le stub Glossary.

**Static object** — Mesh collision/visuel sans comportement Entity.

## W

**WIP (source)** — Page Wiki encore en réécriture. Sur les pages importées : `SOURCE STATUS: WIP`.

**WIP mod** — Mod en développement, dans les docs launcher/setup.
