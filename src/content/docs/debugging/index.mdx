If a step in Getting Started fails, stop there. The original path is designed so launcher, editor, map, and script failures stay separable.

## Fast path

1. Confirm you are in **your copied mod**, not `MinimalCustomMapMod` and not the base game.
2. Launch from the SOMA mod launcher.
3. Press **F1** in development mode: Show Error List, Show HPL Log ([Debug menu](/modding/developer-debug-menu/)).
4. Press **F5** to reload the map after a script change.
5. Read [Developer commands](/modding/developer-commands/).
