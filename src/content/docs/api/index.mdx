This index is built from the Wiki's generated `CodeDoc` pages under `HPL3/SOMA/Scripting`. Most function bodies have **no description** on the original Wiki. The signature, parameter names, and return types are kept. Nothing is filled in from guesswork.

Filter is plain text over name, class, and signature. `cScript_` and `GetGlobalArg` both work.

<ApiBrowser />

## How to read a class page

Each class/category page keeps:

- a function summary table
- per-function signature (AngelScript)
- parameter table
- an “Undocumented” note when the Wiki had no text

Related types (`tString`, `cVector3f`, …) are separate class pages when the Wiki had them.

Gameplay helper groups (`Entity`, `Prop`, `Map`, `Light`, …) live under [api/categories](/api/categories/entity/).
