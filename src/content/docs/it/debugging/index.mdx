Se un passo di Getting Started fallisce, fermati lì. Il percorso originale tiene separati i fallimenti di launcher, editor, mappa e script.

## Percorso veloce

1. Conferma di essere nella **mod copiata**, non `MinimalCustomMapMod` e non il gioco base.
2. Avvia dal SOMA mod launcher.
3. In development mode premi **F1**: Show Error List, Show HPL Log ([Debug menu](/it/modding/developer-debug-menu/)).
4. **F5** ricarica la mappa dopo un cambio di script.
5. Leggi [Developer commands](/it/modding/developer-commands/).
