Ein SOMA-Mod ist ein Ordner, den der Launcher sehen kann. Das Spiel liefert zwei bekannte Beispiele: `MinimalCustomMapMod` und `MinimalAddOnMod`. Kopieren Sie eines davon, statt Dateien von Null zusammenzubauen.

## Einen Mod anlegen

1. [Creating a mod](/de/modding/creating-a-mod/) — types, folder tree, `entry.hpc`, `resources.cfg`
2. [MinimalCustomMapMod](/de/modding/minimalcustommapmod/) — the Getting Started base
3. [MinimalAddOnMod](/de/modding/minimaladdonmod/)
4. [SOMA Mod Launcher](/de/modding/soma-mod-launcher/)
