Une **Area** est un cuboïde invisible dans le niveau. Le hub Areas d’origine appelle les Areas le système d’entrée/sortie principal de HPL3.

<p class="section-kicker">03 // AREAS &nbsp; REF 03.10</p>

Utilisez-les quand quelque chose doit arriver parce que le joueur (ou une autre Entity) est entré dans un volume, a regardé quelque chose, ou parce que le volume lui-même est un effet (fog, soundscape, exposure).

:::caution[SOURCE STATUS: WIP]
Le hub Areas SOMA d’origine est marked as undergoing major editing. Plusieurs types sont listés sans article (redlinks). Leurs paramètres ne sont pas inventés ici.
:::

## Workflow typique

1. Placez l’Area dans le Level Editor (outil Areas).
2. Nommez-la. Nom simple ; les scripts la cherchent par nom.
3. Remplissez les propriétés que le type documente vraiment (collide callbacks, attachment, look-at, champs spécifiques).
4. Si ça déclenche du script, mettez le callback sur le `.hps` de la map (ou un helper file).
5. Testez in-game. S’il ne tire jamais : notes collide-callback de [Trigger Area](/fr/areas/trigger-area/) et [Troubleshooting](/fr/debugging/).

Fichier helper nommé par l’article Trigger : `helper_area.hps`. Les **pages** helper dédiées sont des redlinks ; voir [Helpers](/fr/scripting/helpers/).
