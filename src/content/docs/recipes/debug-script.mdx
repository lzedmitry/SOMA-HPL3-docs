## Goal

See compile errors and log output for the map script.

## Steps

1. [Test, debug, and continue](/start/test-debug-and-continue/)
2. F5 reloads the map
3. F1 → Show Error List / Show HPL Log — [Debug menu](/modding/developer-debug-menu/)
4. [Developer commands](/modding/developer-commands/)

## Expected result

You can reload, read errors, and tell a script failure from a missing-resource failure.

## Common failure

Continuing past a failed checkpoint, so a launch problem looks like a script problem.
