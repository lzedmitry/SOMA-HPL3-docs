Si un paso de Getting Started falla, párate ahí. El camino original separa fallos de launcher, editor, mapa y script.

## Camino rápido

1. Confirma que estás en **tu mod copiado**, no `MinimalCustomMapMod` ni el juego base.
2. Lanza desde el SOMA mod launcher.
3. En development mode pulsa **F1**: Show Error List, Show HPL Log ([Debug menu](/es/modding/developer-debug-menu/)).
4. **F5** recarga el mapa tras un cambio de script.
5. Lee [Developer commands](/es/modding/developer-commands/).
