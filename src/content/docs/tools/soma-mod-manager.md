This application is open-source. The repository can be viewed [here](https://gitlab.com/TiManGames/hpl3-mod-configurator)

The HPL3 Mod Manager is a simple application which makes it easier to manage and configure SOMA mods.
The application removes the need to tamper with configuration files manually. Everything is in one place and can easily be modified.

**Features:**

*Add or create new [mod entries](/modding/creating-a-mod/#mod-entry-file) for easy management.
*Edit mod information: Name, Author, Description, Thumbnail Photo and Mod Type.
*Manage [mod dependencies](/modding/mod-dependencies/) with ease.
*[Sync your mod](/modding/setup-modding-environment/) to the Level Editor: If your mod has any custom assets, the level editor will automatically load it after it's synced.
*Create a [custom .dev launch file](/modding/creating-a-mod/) that will load your mod with your custom scripts and assets
