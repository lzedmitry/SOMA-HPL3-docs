Voice work in SOMA goes through Audition. Pages that exist:

- [Audition overview](/dialogue/audition-overview/)
- [Lip sync](/dialogue/lip-sync/)
- [Voice handler overview](/dialogue/voice-handler-overview/)

The original Audition hub also names Conversations, Voice Settings, and Voice Subjects as part of the system. Dedicated articles for those names were not in the imported tree; treat them as terms used by the overview pages, not as extra manuals.

## Workflow (only steps the overviews support)

Voice file → Audition → conversation / subject setup as described on those pages → trigger in game (script or Area — see the handler overview, do not assume a callback name that the Wiki does not print).
