HPL3 is Frictional Games' in-house engine. SOMA shipped with a SOMA-specific HPL3, including the Level Editor, Model Editor, Material Editor, Particle Editor, and an AngelScript runtime that loads `.hps` map scripts.

## What this docs set covers

This site documents **SOMA's HPL3**. Shared HPL3 articles (Areas, scripting guide, particles, materials) are included when the SOMA tree links to them.

It does **not** mix in Amnesia: Rebirth or Amnesia: The Bunker pages. Those games also say "HPL3" in places. The original Wiki treats them as separate trees because engine features are coupled to the game they shipped with.

The original troubleshooting FAQ says this explicitly: each game has its own documentation instead of one global HPL3 manual.

## What HPL3 is not

- Not a public engine SDK you download besides SOMA
- Not HPL2 (Amnesia: The Dark Descent). Maps are `.hpm`, not `.map`
- Not HPL3.5 / Rebirth tooling, unless a page is marked as shared HPL3
