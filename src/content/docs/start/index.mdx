## What you will make

By the end of this path you will have:

- your own mod folder, copied from `MinimalCustomMapMod`, not from an empty directory
- a stand-alone mod that starts in its sample map
- the Level Editor attached to that mod
- a saved change to an HPL3 `.hpm` map
- a `.hps` map script that prints `Hello World!`

## Before you begin

- Work in **your** mod folder. Do not edit base-game files or the original `MinimalCustomMapMod`.
- An HPL3 map is the `.hpm` file **plus** its `.hpm_*` sidecars. It is not an HPL2 `.map`.
- Names: letters, numbers, underscores.

If you already ship SOMA mods, skip to [Where to go next](/start/where-next/) or open [API reference](/api/).
