This page records what the importer found on **2026-08-28**. It is not legal advice.

## What the task assumed

Older copies of this Wiki were often described as CC BY-SA / GFDL. That had to be re-checked.

## What the Wiki says now

- [Frictional Wiki:Copyrights](https://wiki.frictionalgames.com/page/Frictional_Wiki:Copyrights) redirects readers to the General Disclaimer and About pages. It does **not** name CC BY-SA or GFDL.
- [Frictional Wiki:General disclaimer](https://wiki.frictionalgames.com/page/Frictional_Wiki:General_disclaimer) states that the Wiki and its content are governed by Frictional Games' [Privacy Policy](https://frictionalgames.com/privacy-policy/) and game EULAs, including [EULA: SOMA](https://frictionalgames.com/privacy-policy/eula-soma/).
- MediaWiki `rightsinfo` on the API is empty (no license URL, no license name).
- Contributor terms are framed as EULA §19 (user-created content licensed to Frictional Games), not as a Creative Commons grant to third-party republishers.

## How this site treats that

- This site is unofficial educational documentation.
- Every imported page links to the original Wiki URL and revision.
- Text is restructured; it is not presented as an official Frictional publication.
- Wiki **images were not copied**. File-page license/author metadata was not a clear, separate reuse grant.
- Engine identifiers (function names, file extensions, property names) are facts from the generated API dump.

If Frictional Games or a rightsholder objects to a specific page, file an issue and it can be removed.
