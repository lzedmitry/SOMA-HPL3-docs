## Official (ship with SOMA / HPL3)

| Tool | Role | Required? |
| --- | --- | --- |
| SOMA | Runtime | Yes |
| Level Editor | Maps | Yes for mapping |
| Model Editor | Entities | For custom interactive objects |
| Material Editor | Materials | For custom surfaces |
| Particle Editor | Particles | For custom effects |
| Audition | Voice | For dialogue |
