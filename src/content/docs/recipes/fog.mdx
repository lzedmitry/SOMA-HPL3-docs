## Goal

Visible fog in the map.

## Steps

- **Whole map:** [Level settings](/level-editor/level-settings/) → Global Fog (Active and the other fields that page lists).
- **Volume:** [Fog Area](/areas/fog-area/) and [Fog Areas (level design)](/level-building/fog-areas/).

## Expected result

Fog matches either the global toggle or the local volume.

## Common failure

Editor not working on the mod, so you edited a different map.
