## Goal

An object in the map the player can interact with as a prop.

## Steps

1. [Entity types](/entities/entity-types/) — pick a type the page lists
2. [Physics body properties](/entities/physics-body-properties/)
3. [Joints](/entities/working-with-joints/) only if that page applies
4. Place it: [Working with entities](/level-building/working-with-entities/)

## Expected result

The entity exists in the map with the type you set.

## Common failure

No physics body on a type that needs one — read the physics page instead of guessing.
