La [Glossary source](/it/generated/glossary-source/) originale è marked stub / under construction. Sotto solo i termini che quella pagina o Getting Started / Areas / Modding già usano.

## A

**Add-on** — Una mod che può girare insieme a una stand-alone. Vedi [Creating a mod](/it/modding/creating-a-mod/).

**Agent** — Entity nemico/NPC.

**AngelScript** — Linguaggio degli script `.hps`.

**Area** — Cuboide invisibile, volume I/O di HPL3. Vedi [Areas](/it/areas/).

## C

**Critter** — Piccola creatura di sfondo senza script agent completo.

## E

**Entity** — Oggetto di mondo con comportamento. Vedi [Entities](/it/entities/).

**entry.hpc** — File di entry della mod.

## H

**Helper** — Include di script condiviso. Meccanismo: [Helper files](/it/scripting/helper-files/). Pagine Wiki per helper: mancanti.

**HPL3** — Motore con cui è uscita SOMA. Non automaticamente lo stesso «HPL3» di Amnesia successiva. Vedi [What is HPL3?](/it/start/what-is-hpl3/).

**HPM** — File mappa (`.hpm` + `.hpm_*`).

**HPS** — Sorgente AngelScript (`.hps`).

## I

**ID handle** — Identità script di un oggetto motore. [ID Handles](/it/scripting/id-handles/).

## M

**Mod** — Contenuto extra nella propria cartella.

## P

**Prop** — Entity interattiva. La maggior parte delle Entity sono props.

## R

**resources.cfg** — Dice al motore quali directory di risorse cercare.

## S

**SH probe** — Spherical-harmonic lighting probe. Nominata sull’hub Level Design; l’articolo SOMA è un redlink.

**Stand-alone mod** — Mod di mappe custom avviata dal SOMA mod launcher. Nel stub Glossary anche custom story.

**Static object** — Mesh di collisione/visuale senza comportamento Entity.

## W

**WIP (source)** — Pagina Wiki ancora in riscrittura. Sulle pagine importate: `SOURCE STATUS: WIP`.

**WIP mod** — Mod in sviluppo, nei documenti launcher/setup.
